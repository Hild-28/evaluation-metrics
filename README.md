# Evaluation Metrics for Computer Vision Tasks

This project explains and implements the evaluation metrics of three computer vision tasks:

1. **Image classification** (binary, multiclass, multilabel)
2. **Object detection**
3. **Semantic and instance segmentation**

Every metric is computed **by hand with NumPy** on small, easy-to-follow examples, so that each step is visible. The results are then checked against **scikit-learn** whenever an equivalent function exists.

> The notebooks are saved **with their results**, so they can be read directly on GitHub without running anything.

---

## Repository structure

```
evaluation-metrics-cv/
├── README.md                  # this documentation
├── requirements.txt           # Python dependencies
├── metrics.py                 # all metric functions (documented below)
├── 01_classification.ipynb    # task 1: image classification
├── 02_detection.ipynb         # task 2: object detection
├── 03_segmentation.ipynb      # task 3: semantic and instance segmentation
└── figures/                   # charts generated by the notebooks (used in the presentation)
```

- **`metrics.py`** contains the reusable functions: each one has a docstring describing its inputs and output.
- **The notebooks** explain each metric (idea → formula → calculation → check → figure → takeaway) and use the functions from `metrics.py`.

## The notebooks

### 01 · Image classification
**Use case:** a model screening chest X-rays (sick / healthy).

| Section | Metrics | Key result |
|---|---|---|
| Binary | Confusion matrix, accuracy, precision, recall, F1, threshold, ROC-AUC | A lazy model that always answers "healthy" gets **80% accuracy** while finding **0** sick patients |
| Multiclass | N×N confusion matrix, per-class metrics, macro / weighted / micro F1, top-1 / top-5 | Accuracy 0.85, but **macro F1 0.76** reveals the weak "bird" class |
| Multilabel | Subset accuracy, Hamming loss, per-label F1 | Subset accuracy 0.33 (strict) vs. Hamming loss 0.22 (forgiving) |

### 02 · Object detection
**Use case:** a camera that must find every person in an image.

| Section | Metrics | Key result |
|---|---|---|
| Matching | Box IoU, TP / FP / FN | 5 boxes → 3 TP, 2 FP |
| Precision / recall | Effect of the confidence threshold | From 1.00 / 0.33 (strict) to 0.60 / 1.00 (loose) |
| AP | Ranked-list method | AP = 0.87; the **same boxes in a different order** give 1.00 or 0.48 |
| mAP | Pascal VOC (IoU ≥ 0.5) vs. COCO (IoU 0.5 to 0.95) | **0.87 vs. 0.60**: COCO also demands precise boxes |

### 03 · Semantic and instance segmentation
**Use case:** a self-driving car's view of the street (road, sky, pedestrians).

| Section | Metrics | Key result |
|---|---|---|
| Binary masks | Pixel accuracy, IoU, Dice | 0.80 / 0.50 / 0.67; a model that colors nothing still gets 70% pixel accuracy |
| Semantic | Per-class IoU, mIoU | Pixel accuracy 0.86 but **mIoU 0.65** (pedestrians poorly found) |
| Instance | Mask IoU, mask AP | Two models with **identical pixels**: mask AP **1.00 vs. 0.17** when two pedestrians are merged |
| Bonus | Panoptic Quality (PQ = SQ × RQ) | PQ 0.88 vs. 0.35, same shape quality but worse recognition |

## Documentation of `metrics.py`

### Classification

| Function | Inputs | Output | What it computes |
|---|---|---|---|
| `binary_counts(y_true, y_pred)` | Arrays of 0/1 | `(tp, fp, fn, tn)` | Binary confusion matrix |
| `accuracy(y_true, y_pred)` | Arrays of labels | float | (TP + TN) / total |
| `precision(tp, fp)` | Counts | float | TP / (TP + FP) |
| `recall(tp, fn)` | Counts | float | TP / (TP + FN) |
| `f1(tp, fp, fn)` | Counts | float | 2·TP / (2·TP + FP + FN) |
| `apply_threshold(scores, threshold)` | Scores in [0, 1], threshold | Array of 0/1 | Turns scores into decisions |
| `roc_auc_pairs(y_true, scores)` | Labels 0/1, scores | float | ROC-AUC = probability that a positive scores higher than a negative |
| `confusion_matrix(y_true, y_pred, n_classes)` | Class indices | N×N array | Rows = truth, columns = prediction |
| `per_class_counts(cm)` | Confusion matrix | `(tp, fp, fn)` arrays | TP = diagonal, FN = rest of row, FP = rest of column |
| `per_class_metrics(cm)` | Confusion matrix | `(precision, recall, f1)` arrays | Metrics for each class |
| `averaged_f1(cm, average)` | Matrix, `"macro"` / `"weighted"` / `"micro"` | float | F1 averaged over classes |
| `top_k_accuracy(true_labels, ranked_guesses, k)` | True labels, ranked guesses | float | Correct if the true label is in the first k guesses |
| `subset_accuracy(Y_true, Y_pred)` | 0/1 matrices (images × labels) | float | Fraction of images with all labels exactly right |
| `hamming_loss(Y_true, Y_pred)` | 0/1 matrices | float | Fraction of wrong yes/no decisions (lower is better) |
| `multilabel_counts(Y_true, Y_pred)` | 0/1 matrices | `(tp, fp, fn)` per label | Counts for per-label metrics |

### Object detection

| Function | Inputs | Output | What it computes |
|---|---|---|---|
| `box_iou(a, b)` | Two boxes `(x_min, y_min, x_max, y_max)` | float | Intersection area / union area |
| `match_predictions(preds, gts, iou_fn, iou_threshold)` | `[(box_or_mask, score)]`, real objects, IoU function, threshold | List of dicts sorted by confidence | Greedy matching: most confident first, each real object matched once |
| `average_precision(rows, n_gt, interpolated=False)` | Matching result, number of real objects | float | AP with the ranked-list method (optionally with the official smoothing rule) |
| `ap_over_iou_thresholds(preds, gts, iou_fn, thresholds)` | Predictions, real objects, IoU function | `(thresholds, aps)` | AP at IoU 0.50 … 0.95; their mean = COCO-style mAP |

### Segmentation

| Function | Inputs | Output | What it computes |
|---|---|---|---|
| `pixel_accuracy(gt_mask, pred_mask)` | Two masks | float | Correct pixels / total pixels |
| `mask_iou(gt_mask, pred_mask)` | Two binary masks | float | TP / (TP + FP + FN) |
| `dice(gt_mask, pred_mask)` | Two binary masks | float | 2·TP / (2·TP + FP + FN) |
| `per_class_iou(cm)` | Confusion matrix | Array | IoU of each class |
| `mean_iou(cm)` | Confusion matrix | float | mIoU = average of per-class IoUs |
| `panoptic_quality(preds, gts, iou_threshold)` | `[(mask, score)]`, real masks | `(PQ, SQ, RQ)` | PQ = SQ × RQ (simplified, one class) |

## Notes and simplifications

- The examples are **toy examples** (a few images, a 30 × 30 pixel scene) chosen so every number can be checked by hand.
- `average_precision` uses the simple ranked-list method by default. Official benchmarks (Pascal VOC, COCO) add a smoothing ("interpolation") rule; it is available with `interpolated=True` and gives very close results.
- For real projects, use the official tools: `scikit-learn` for classification, `pycocotools` (COCO API) or `torchmetrics` for detection and segmentation.
